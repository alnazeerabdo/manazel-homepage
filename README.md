# منازل الإبداع — Homepage refresh

A responsive RTL Arabic homepage prototype built with plain HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a browser. No build tools or package installation are required.

## Files

- `index.html` — page structure and Arabic content
- `styles.css` — responsive layout, typography and visual design
- `script.js` — mobile navigation, scroll reveal, active navigation and project filters

## Brand notes

The live page's extracted text does not expose its CSS design tokens or font declarations. This prototype uses an editable forest-green / warm-gold / ivory palette and Cairo Arabic type as a premium real-estate direction. Change the variables at the top of `styles.css` and the Google Fonts link in `index.html` to match the official brand values if you have them.

Project facts shown in the prototype are limited to details found on the public Manazel project page. Photography is illustrative and should be replaced with approved company project photography before production.
